How to read a result

Each field is USAC's, with USAC's own note for it from its data dictionary.

Make and model
USAC: “Manufacturer for the FRN line item product.” And: “Model of the equipment on FRN Line Item.” Both are as the applicant entered them. “Other” is USAC's value for a make not on its list; the applicant's own description follows it.
Quantity and unit cost
USAC's columns “FRN Line One-Time Quantity” and “FRN Line One-Time Eligible Unit Cost”. The unit cost is before the E-Rate discount and leaves out any ineligible share. On the 217 lines this page was tested with (four districts, USAC data of November 6, 2026), quantity × unit cost equals the line's eligible one-time total.
Monthly cost
USAC: “Pre-discounted eligible monthly charges for the FRN line item.” Shown with the number of months of service in that funding year.
Bandwidth
USAC: “Download speed of the connection for the FRN line item service.” Upload speed is shown after it.
Funded
USAC: “Status of the funding request. It includes pending, funded, denied or cancelled.” Only funded requests are listed; the others are counted under “Left out”.
Committed and disbursed
USAC: “The total amount for the Funding Request (FRN) after discount.” And: “Total net amount disbursed to a service provider or applicant.” A funded request with nothing disbursed may not be invoiced yet, or may never have been bought with E-Rate funds; the summary and the card mark it.
Contract ends
USAC: “Contract expiration date for the FRN. If the FRN is for a tariff or month-to-month service this field displays the service end date.” Where USAC has one, the extended date follows: “Contract expiration date for contracts that can be extended.”
Service provider
USAC: “Service provider name for the FRN.” A name that reads as a person's own name is not shown.

What it can't show

  • Equipment bought without E-Rate funding: with local funds, grants or donations, or the ineligible share of a purchase.
  • Purchases filed under another billed entity number (BEN). The page matches the BEN on the Form 470, so a member school's own requests, or a consortium's, don't show.
  • Whether the equipment is still in service. A funded request is a commitment; “disbursed” shows what USAC paid.
  • Requests that weren't funded (pending, denied or cancelled), and FY2016 and earlier.

Where the data comes from

  • The form: USAC Open Data, E-Rate FCC Form 470 Tool Data (dataset jt8s-3q52, Public Domain). One query per lookup, by application number, 24 named fields, no contact field. USAC's data holds each form as last modified (“Current”) or as first certified (“Original”); this page uses Current where USAC has it. If the form isn't there, one more query counts that funding year's forms.
  • The purchases: USAC Open Data, E-Rate Request for Discount on Services: FRN Line Items (dataset hbj5-2bpj, Public Domain). One query per lookup (one more per 5,000 lines): the Current version of every FY2017–FY2026 line item filed under the form's BEN, 24 named fields, no contact field.
  • Funding status and provider: USAC Open Data, E-Rate Request for Discount on Services: FRN Status (dataset qdmp-ygft, Public Domain). One query per lookup, 13 named fields, no contact field.
  • “Data as of” is each dataset's last update as USAC's server reports it (its Last-Modified time).
  • Left out: lines on requests that weren't funded, and applicants whose name suggests a health-care operator. A provider's name is shown only when it reads as a business or public body. No person's name, email or phone number is ever requested from USAC or shown.
  • Westworks counts visits and lookups on this page, never the Form 470 number.
